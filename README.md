# D.S

Eşleş • Düello • Sıralama

Pyramid Game'den tamamen bağımsız yeni oyun.

## Nasıl Oynanır?

1. Kayıt ol / Giriş yap
2. Oda kur veya katıl
3. Sıralama ekranında **Eşleş** butonuna bas
4. En az 2 kişi Eşleş'e basınca rastgele eşleşirsiniz
5. İkiniz de **Başlat**'a basın
6. Ortadaki kırmızı **PES** butonuna basan kaybeder
7. Kazanan sıralamada yükselir

## Teknik

- Aynı Firebase projesi kullanılıyor (pyramid-oyun)
- Firestore: `ds_rooms`, `ds_users` koleksiyonları
